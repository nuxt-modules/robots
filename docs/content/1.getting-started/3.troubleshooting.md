## Debugging

**Nuxt DevTools.** The best tool for debugging is the Nuxt DevTools integration with Nuxt Robots. This will show you the current robot rules and your robots.txt file.

**Debug config.** You can enable the [debug](/docs/robots/api/config#debug) option which will give you more granular output. This is enabled by default in development mode.

## Google still uses the previous rules

Check the deployed robots.txt response first. Google [generally caches robots.txt for up to 24 hours](https://developers.google.com/crawling/docs/robots-txt/robots-txt-spec), and fetch errors can extend caching. Compare its robots.txt report with your current response.

[Google Search timelines](https://nuxtseo.com/learn-seo/google-search-timelines) explains why a live fix and Google's adoption are separate observations.
